## 💡 Overview

**SketchDirector** is an agentic framework for **text-guided multi-concept scene sketch generation**. Given a textual scene description, SketchDirector first generates independently editable object-level SVG sketch assets, then organizes them into a spatially coherent composition through **agentic layout reasoning**, and finally enhances sketch details through **detail refinement**.

Unlike approaches that treat an entire scene as a single indivisible image, SketchDirector represents each scene as a collection of vector objects composed of cubic Bézier curves. This representation supports **object-level manipulation, executable layout adjustments, and object- and path-level editing**.

<p align="center">
  <img src="./img/main_framework.jpg" alt="SketchDirector framework" width="100%" />
</p>

**Key Features:**

- **Independently editable vector assets:** Represent visual concepts in a scene as separate SVG objects.
- **Agentic layout reasoning:** Progressively construct and correct scene compositions through a Plan–Execute–Verify–Correct loop.
- **Self-evolving memory:** Leverage short-term failure memory and long-term successful experiences to guide layout correction.
- **Structure-aware detail refinement:** Improve local sketch details and overall visual quality while preserving object structures and spatial layouts.

## 📊 MCSketch8K Dataset

To support research on **multi-concept scene sketch generation and controllable editing**, we introduce **MCSketch8K**, a structured dataset comprising **1,000 scene sketches, over 4,000 independently editable SVG object assets, and more than 800 object categories**.

The 1,000 scene descriptions are generated by a large language model (LLM). Based on these descriptions, the dataset is constructed using **SketchDirector**, which generates object-level vector assets, compositional scene layouts, and corresponding manipulation annotations. MCSketch8K provides structured resources for **object-level scene composition and spatial layout reasoning**.

The dataset is publicly available on [Hugging Face](https://huggingface.co/datasets/yiki77/MCSketch8K).


## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Yiki77/SketchDirector.git
cd SketchDirector
```

### 2. Create a Conda Environment

```bash
conda create -n sketchdirector python=3.9
conda activate sketchdirector
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

Install the PyTorch packages for CUDA 11.8:

```bash
pip install \
  torch==2.5.1+cu118 \
  torchvision==0.20.1+cu118 \
  torchaudio==2.5.1+cu118 \
  --index-url https://download.pytorch.org/whl/cu118
```

> The configuration above targets **CUDA 11.8**. Check compatibility with your GPU, CUDA Toolkit, and operating system. This installation procedure has not been independently tested against the current repository.


## 🎨 Refinement Dependencies

## ▶️ Quick Start

### Single-Scene Generation

```bash
python -m sketchdirector \
  --concept_to_draw "A ship moving on the water." \
  --skip_refinement
```

The `--skip_refinement` flag runs only object asset generation and agentic layout reasoning, skipping diffusion-guided detail refinement.

### Batch Generation

Add one scene description per line to `examples/prompts.txt`, for example:

```text
A cat sleeping on a sofa.
A man reading a newspaper on a bench.
Two stone lions stand on either side of the temple steps.
```

Run:

```bash
python -m sketchdirector \
  --concept_file examples/prompts.txt \
  --skip_refinement
```



## ✨ Run the Full Pipeline

To run the complete pipeline with detail refinement, remove `--skip_refinement` and configure the required models:

```bash
python -m sketchdirector \
  --concept_file examples/prompts.txt \
  --rf_model_path ./2_rectified_flow_from_sd_1_5 \
  --base_sd_model_path ./stable-diffusion-v1-5 \
  --tuned_model_path yykkL123/vector_style_sd1.5
```

The resulting sketches are saved as **SVG files** in the `output_sketches` folder.

**Model Resources:**

| Model | Link |
| --- | --- |
| `Rectified Flow` | [Model](https://huggingface.co/XCLiu/2_rectified_flow_from_sd_1_5) |
| `Stable Diffusion v1.5` | [Model](https://huggingface.co/ruwnayml/stable-diffusion-v1-5) |
| `Vector Style SD1.5` | [Model](https://huggingface.co/yykkL123/vector_style_sd1.5) |

**Main Arguments:**

| Argument | Description |
| --- | --- |
| `--concept_to_draw` | Textual description of a single scene |
| `--concept_file` | Path to a text file containing scene descriptions for batch generation |
| `--skip_refinement` | Skip the structure-aware detail refinement stage |
| `--rf_model_path` | Path to the Rectified Flow model |
| `--base_sd_model_path` | Path to the base Stable Diffusion model |
| `--tuned_model_path` | Local path or supported Hugging Face model identifier for the sketch-style fine-tuned model |



## 🛠️ Troubleshooting

### `pydiffvg` Installation Failed

Check compatibility among PyTorch, the CUDA Toolkit, Python, your C++ compiler, and related dependencies. See the [official DiffVG installation instructions](https://github.com/BachiLi/diffvg#install).

### API Request Failed

Check `OPENAI_API_KEY`, `OPENAI_BASE_URL`, your network connection, and whether your API provider supports the model used by the code.

### Run Layout Reasoning Without Detail Refinement

Add the following flag to your command:

```text
--skip_refinement
```

This skips the detail refinement stage and its additional model requirements.
